# システムストレージスキャン器

システム全体のストレージをスキャンし、巨大で不要なディレクトリを特定する Rust スクリプトです。

## 機能

- **巨大ディレクトリの検出**: 100 MB 以上サイズのディレクトリを特定
- **不要ディレクトリの特定**: キャッシュ、ログ、テストファイル、仮想環境など削除候補となるディレクトリを特定
- **詳細レポート**: 各ディレクトリのサイズと理由を表示

## 使用方法

```bash
# 直接実行
cargo run --release

# または
rustc src/main.rs -o storage-scanner
./storage-scanner
```

## 対象ディレクトリ

以下のルートディレクトリをスキャンします：
- `/home`
- `/root`
- `/tmp`
- `/var`
- `/opt`
- `/usr`

## 検出されるカテゴリ

### 大容量ディレクトリ (>100 MB)
- 巨大なプロジェクトディレクトリ
- 古いビルド成果物
- 大きなデータベースキャッシュ
- 他の巨大なアプリケーション

### 不要なディレクトリ（削除候補）
- `node_modules/` - npm/yarn 依存関係
- `target/` - Rust/Cargo ビルド成果物
- `build/` - ビルド出力
- `.cache/` - キャッシュディレクトリ
- `venv/` / `virtualenv/` - Python 仮想環境
- `test/` / `spec/` - テストディレクトリ
- `old/` - 古いバージョン
- `snap/` - Snap 旧バージョン
- `.local/` - GNOME カーネルキャッシュ
- ログファイル/ディレクトリ
- 仮想ファイルシステム (/proc, /sys, /dev)

## 出力例

```
=== ストレージスキャン報告 ===
探索ディレクトリ数: 42

所要時間: 12.34 秒

--- 大容量ディレクトリ (100 MB 超え) ---
  パス: /home/user/project/build
    サイズ: 245.6 MB
    理由: サイズが245.6 MB を超えています

--- 不要なディレクトリ（削除候補） ---
  パス: /home/user/.cache
    サイズ: 12.3 MB
    理由: 古いキャッシュディレクトリ
  パス: /home/user/node_modules
    サイズ: 85.2 MB
    理由: Rust/Cargo ビルド成果物（再ビルド可能）
  パス: /home/user/venv
    サイズ: 45.6 MB
    理由: Python 仮想環境（不要な場合再作成可能）

=== 終了 ===
```

## 注意点

- システムの重要なディレクトリ（/bin, /sbin, /usr/lib, /etc など）はスキャンから除外されます
- 権限のないディレクトリはスキップされます
- 実行前に `cargo build` を実行して依存関係を解決してください
